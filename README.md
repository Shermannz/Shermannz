## Sobre mim

Sou desenvolvedor **Back-end com foco em C# e .NET**, com experiência em desenvolvimento de aplicações web e APIs.

Tenho interesse em construir soluções bem estruturadas, com responsabilidades bem definidas, persistência consistente e mecanismos seguros de autenticação e autorização.

**Principais áreas de interesse:**

- Desenvolvimento de APIs REST com ASP.NET Core.
- Arquitetura em camadas e separação de responsabilidades.
- Modelagem de dados e relacionamentos.
- Entity Framework Core e Dapper.
- Autenticação e autorização com JWT.
- Integração com bancos de dados relacionais.

Também possuo conhecimentos em Java/Spring Boot e tecnologias de front-end.

Atualmente, curso **Análise e Desenvolvimento de Sistemas na Faculdade Descomplica**.

**Objetivo profissional:** atuar como desenvolvedor Back-end .NET em regime CLT.
